# West Bromwich Albion — Independent Rebranding Concept Proposal

A self-initiated brand identity proposal by Park Jaeyoung / NINEWORKS.

## Concept

**LESS DETAIL. MORE ALBION.**

The proposal preserves the Throstle, Hawthorn, Navy & White and the name ALBION while refining how those assets perform across contemporary football culture.

## Status

This is an independent proposal and was not commissioned, endorsed or approved by West Bromwich Albion Football Club. Implementation has not been confirmed and the proposal is currently under review.

## Structure

- `index.html` — proposal landing page
- `styles.css` — responsive visual system
- `script.js` — smooth navigation and reveal interactions
- `.nojekyll` — GitHub Pages compatibility
